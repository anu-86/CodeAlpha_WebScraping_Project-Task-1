# CodeAlpha Data Analytics Internship - Task 1: Web Scraping

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship Program. The objective was to collect data from a public website using web scraping techniques and create a structured dataset for further analysis.

## Objective

To extract book information from a website and store the collected data in a CSV file using Python.

## Website Used

Books to Scrape

## Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas

## Data Extracted

The following information was collected:

* Book Title
* Price
* Rating

## Project Workflow

1. Connected to the website using the Requests library.
2. Parsed the HTML content using BeautifulSoup.
3. Extracted book details such as title, price, and rating.
4. Stored the extracted data in a Pandas DataFrame.
5. Exported the dataset to a CSV file for further analysis.

## Output

The scraped data was successfully saved as:

books_data.csv

## Learning Outcomes

* Understanding web scraping concepts
* Working with HTML page structures
* Using BeautifulSoup for data extraction
* Creating datasets with Pandas
* Exporting data to CSV format
